# Agent Workflow Guide

AI agents should treat `AGENTS.md` as the entry point and `specs/` as the durable contract.

For a normal editing task:

```text
1. Read AGENTS.md.
2. Read task.md and config.md.
3. Read the relevant spec.
4. Make the smallest implementation change.
5. Update examples if public API changes.
6. Run the relevant compile command.
7. Report changed files and verification.
```
