# Natural Hazards Remote Sensing Lab Logo Spec

## Canonical Asset

Use this file as the default lab logo:

```text
figures/lab-logo/Natural_Hazards_Remote_Sensing_Lab_logo_nhrs_lab_transparent.png
```

This repository no longer uses generated `nhrs-lab-*` SVG/PNG candidates. The canonical logo is the transparent PNG supplied at the repository root and moved into `figures/lab-logo/`.

The CUES files are official identity assets and should be used when a formal college lockup is needed.

## Identity Text

- Lab: Natural Hazards Remote Sensing Lab / NHRS Lab
- Affiliation: PKU CUES

`PKU CUES` must remain visible in lab-facing slide templates. The affiliation is part of the lab identity, not an optional caption.

## Usage Notes

- Use the transparent PNG on light slide backgrounds.
- Use the chroma or plain PNG only when the transparent asset has insufficient contrast.
- Keep PKU/CUES identity restrained but visible.
- Do not recreate or replace the supplied logo with generated alternatives.
- The supplied logo already includes remote-sensing, terrain, hazard, and seismic-wave elements.
- Use `figures/identity/CUES_long_rect_logo_transparent_cropped.png` for the lab cover/end page CUES lockup on light or photographic backgrounds.
