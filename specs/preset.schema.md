# Preset Schema

Presets describe reusable context. They should not contain deck-specific content.

## Language Preset

Owns:

- labels
- date style
- font preference
- agenda/reference/end-page wording

Examples: `en`, `cn`.

## Venue Preset

Owns:

- palette intent
- footer/header policy
- logo policy
- metadata density
- expected formality

Examples: `pku`, `agu`, `egu`, `generic`, `group`.

## Objective Preset

Owns:

- default section sequence
- slide rhythm
- expected components
- default emphasis

Examples: `conference`, `group-meeting`, `collaborator-briefing`, `defense`, `paper-discussion`.

## Density Preset

Owns:

- text scale intent
- spacing intent
- caption/detail level

Examples: `light`, `normal`, `dense`.
